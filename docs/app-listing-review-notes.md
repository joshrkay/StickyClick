## Theme extension onboarding

For complete reviewer and merchant onboarding, including install, Theme Editor setup, enabling the `sticky-button` app block, publishing, settings configuration, and troubleshooting, use:

## Reviewer validation summary

- Install StickyClick in a development store.
- Add/enable the `sticky-button` app block in Theme Editor.
- Save and publish theme updates.
- Verify Upsell, Quick Buy, and Cart Drawer behavior on product pages.
